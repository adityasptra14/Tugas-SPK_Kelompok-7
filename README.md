# SmartKost Decision
KostRank – Smart Decision System merupakan aplikasi berbasis web yang dirancang untuk membantu pengguna dalam memilih kost terbaik secara objektif dan terstruktur. Aplikasi ini menerapkan metode Simple Additive Weighting (SAW) sebagai dasar perhitungan dalam sistem pendukung keputusan.
Melalui aplikasi ini, pengguna dapat memasukkan beberapa alternatif kost beserta kriteria penilaian seperti harga, jarak ke lokasi, fasilitas (kamar mandi, listrik, AC), ukuran kamar, dan rating. Sistem kemudian akan melakukan normalisasi dan perhitungan nilai preferensi untuk menghasilkan peringkat kost terbaik berdasarkan bobot kriteria yang telah ditentukan.
Dengan pendekatan ini, proses pemilihan kost menjadi lebih efisien, transparan, dan tidak subjektif, sehingga membantu pengguna dalam mengambil keputusan yang lebih tepat sesuai kebutuhan.

## Fitur
- Input data kost
- Ranking otomatis
